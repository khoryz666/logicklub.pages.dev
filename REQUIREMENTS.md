# Requirements

This document outlines the academic requirements, core deliverables, and grading criteria for the **LOGICKlub** group assignment based on the official course guidelines.

---

## Key Information & Deadlines
* **Course Code**: UCCD2323 Front-End Web Development
* **Weightage**: Group Assignment (20% of total grade)
* **Submission Date**: **21 August 2026, Friday, Week 10 (by 5:00 PM)**
* **Turnitin Similarity Limit**: Must be **below 20%** (Class ID: 53657404, Key: FEWD_JUNE26)

---

## Core Deliverables
The group must compile and submit the following files (compressed into a single ZIP file named `UCCD2323_GroupName.zip`):
1. **Written Report (`UCCD2323_GroupName.docx`)**:
   * Assignment cover page with grading marksheet included right after it.
   * Members' contribution sheet (signed by all members).
   * Table of Contents.
   * **Chapter 1**: Introduction (Audience & Goals).
   * **Chapter 2**: Literature Review (Analysis of at least 3 existing websites).
   * **Chapter 3**: Design (Wireframes, Mockups, and Site Map).
   * **Chapter 4**: Evaluation (User Manual with screenshots).
   * References & Appendix (IEEE format, containing PowerPoint slides).
2. **Complete Source Code**:
   * HTML, CSS, JavaScript, WebAssembly, and configuration assets.
3. **Presentation & Demo Video (`UCCD2323_GroupName.mp3` or `.mp4`)**:
   * **Max duration**: 25 minutes (strictly no playback acceleration allowed).
   * Every member must present their assigned pages and explain code implementations.
   * Includes a Q&A session at the end (each member must ask 1 question and answer 1 question; questions must be displayed on screen).

---

## Website Technical Requirements

To secure maximum marks, the website code must satisfy the following constraints:

### 1. Structure & Distribution
* **Page Count**: Minimum **8 pages** for a 4-member group.
* **Division**: Each member must fully develop and claim contribution for **exactly 2 pages**.
* **Responsiveness**: The site must be completely mobile-responsive using **Bootstrap 5.3**.
