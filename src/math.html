Matrixes: One of the concepts in math that drive AI

AI now is changing our live constantly, regardless of LLMs such as ChatGPT, Gemini, Claude or other domains such as computer vision. Behind these technologies, linear algebra is one of the key concepts that power them. The essence of linear algebra is of course matrices, which is nothing but an organized set of numbers.

Domain Spotlight: Computer Vision

In Computer Vision, an AI doesn't see a picture of a cat the way we do. It sees a massive grid of numbers representing pixel colors. This grid is called a Matrix.

To help the AI recognize the cat whether the image is tilted, stretched, or squished, the AI applies mathematical filters called Matrix Transformations. By multiplying the image matrix by a transformation matrix, the AI can rotate, scale, or shear the image mathematically.

Furthermore, when an AI tries to classify data (e.g., separating Cat images from Dog images), it plots them as points in "data space". The AI's learning process is literally just finding the perfect matrix to warp that space so that Cats and Dogs end up neatly separated on opposite sides!

Why can I only drag two points on the graph?

In Linear Algebra, the whole 2D space is built from just two special arrows. One points right (red). The other points up (green). We call them Basis Vectors (term: basis vectors).

Think of these two arrows like the "building blocks" of the entire grid. Every other point in space is just a combination of these two arrows. For example, the point (3, 2) means "go 3 steps right and 2 steps up" — that's 3 red arrows and 2 green arrows added together.

A matrix transformation keeps grid lines straight and evenly spaced. It never bends or warps them in a messy way — it only stretches, squishes, or rotates the whole grid uniformly. So if we know where the two basis vectors land, we know where everything else lands. Because every other point is just a combination of the basis vectors, we can calculate its new position from the new positions of the red and green arrows.

Drag the red point — you are changing the first column of the matrix (the a and b values). Drag the green point — you are changing the second column (the c and d values). The rest of the space just follows along automatically.

Terms: Matrix — a grid of numbers that defines the transformation. Each column tells us where one basis vector goes. Column — each basis vector becomes one column in the matrix. The first column is where the red arrow lands, the second column is where the green arrow lands. Linear Transformation — a rule that moves every point in space while keeping grid lines straight and evenly spaced.

How does this relate to Neural Networks?

A Neural Network takes input data (like pixel values from an image) and sends it to the first layer. Each input is like a point in space — for example, a 28x28 grayscale image has 784 pixel values, so it lives in a 784-dimensional space.

That first layer applies a matrix transformation — it "stretches" and "rotates" the data in that high-dimensional space. This is exactly what you see happening on the graph, but with many more dimensions! The transformation moves the data around, trying to make it easier to work with.

The transformed data goes to the next layer, which applies another transformation. This keeps happening layer by layer. Each layer has its own matrix (called "weights") that it uses to transform the data.

The network learns by adjusting these transformations over time. At first, the transformations are random — the data ends up in random places. But as the network sees more examples, it slowly tweaks the numbers in the matrices (the weights) so that the data ends up in the right place.

For example, imagine you have pictures of cats and dogs. The network applies many transformations, and eventually, it moves all the "cat" data into one zone and all the "dog" data into another zone. Then, when a new picture comes in, the network checks which zone it lands in and says "cat" or "dog" correctly.

Terms: Neural Network — a system of layers that transform data step by step. Weights — the numbers inside the matrix that get adjusted during learning. They are the "knobs" the network turns to get better. Layer — one step of transformation in the network. Each layer applies its own matrix to the data. Bias — an extra number added after the transformation that helps shift the data around (like moving the whole grid up or down). Learning — the process of adjusting weights and biases so that the network's output gets closer to the correct answer.
